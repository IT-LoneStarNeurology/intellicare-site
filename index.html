IntelliCare reads the chart you already have open and gives you a quiet nudge exactly when it matters, so nothing about the visit slips by.

Add to Chrome*

*Requires Chrome 138 or newer. AI summaries run on Windows 10/11 or macOS 13+ with at least 22 GB of free disk space and either a GPU with more than 4 GB of VRAM or 16 GB of RAM and 4+ CPU cores. Where those aren't met, everything else still works and summaries show the notes as written.

What it does for you

Four quiet things, running in the background

Documentation reminders

A quiet note the moment something's worth a second look, right there while you're still charting.

Continuity of care

A short summary of what's happened since the last visit, added right into the note as you start documenting.

Abnormal labs, surfaced

Results worth knowing about before the next visit, pulled up automatically instead of buried in the chart.

Runs entirely on-device

Summaries are generated by Chrome's own built-in AI, right in your browser. Nothing about your notes ever leaves this computer.

Get set up

One click, nothing to install

  1. 1

    Add the extension to Chrome

    Click Add to Chrome above and install it like any other extension.

  2. 2

    Generate a pairing code

    Open the extension's Options page and click Generate pairing code.

  3. 3

    Give the code to IT

    Your practice's IT contact approves new devices from the admin console.

  4. 4

    You're live

    The extension goes from pending to active automatically the moment it's approved. Nothing more to do here.
